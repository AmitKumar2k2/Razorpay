# Razorpay-Inspired FinTech UI  
A modern, animated, fully responsive FinTech interface built using **React**, **Vite**, **Tailwind CSS**, and **GSAP**.  
The project includes a premium hero section, parallax card animations, scroll-trigger effects, floating backgrounds, and reusable UI components.

## Features  
- Razorpay-style Hero Section  
- Parallax Card Stack (3D + Floating + Mouse Tilt)  
- Fully Responsive (Mobile-first)  
- Smooth GSAP Scroll Animations  
- Floating Animated Background Objects  
- Animated Number Counters  
- Custom Fluid Buttons with Hover Fill  
- Feature Cards with Scroll Reveal  
- Clean, Reusable, Component-based Architecture  

---

## Tech Stack  

### **Frontend**
- **React.js**
- **Vite** (Dev bundler)
- **Tailwind CSS**
- **GSAP**  
  - `ScrollTrigger`  
  - `Draggable`  
- **Lucide-react** (icons)
- **Unsplash images** (free assets)
